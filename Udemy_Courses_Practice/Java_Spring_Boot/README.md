# Java and Spring Boot Example

## How to Run

1. Import into your IDE (Eclipse/IntelliJ)
2. Run the main class `Application.java`
3. Open browser: `http://localhost:8081/api/products`

## Features
- Spring Boot RESTful API
- JSON response with hardcoded product list

## Output Sample

```json
[
  {
    "id": 1,
    "name": "Laptop",
    "price": 50000.0
  },
  {
    "id": 2,
    "name": "Phone",

  }
]
```
