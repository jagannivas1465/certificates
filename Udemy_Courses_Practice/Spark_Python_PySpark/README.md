# Spark + Python + PySpark Mega Course Example

This is an example project inspired by the "Spark and Python for Big Data with PySpark" Udemy course.

## What It Demonstrates

- Starting a Spark session
- Creating a DataFrame from a list of tuples
- Grouping and aggregation (average salary by department)
- Writing results to CSV format

## How to Run

1. Install PySpark if you haven't:

```bash
pip install pyspark
```

2. Run the script:

```bash
python spark_python_pyspark_mega_course.py
```

3. Output will be stored in the `output/department_avg_salary` directory.

## Use Case

This simulates a payroll analytics task where you compute average salaries by department for a company.
